# Demo narration and chapters

Duration: 2 minutes 50 seconds. English synthetic voice, generated locally.

## 00:00 — AI BLIND ASSISTANT  /  PROJECT DEMONSTRATION

Meet AI Blind Assistant, an Android app that turns object observations and printed text into spoken information. Let's follow a user's journey.

## 00:10 — 01  /  OPEN THE APP

From Home, the user opens Mobile Mode or chooses another feature. Large labelled controls expose the assistance status, while TalkBack support and on-demand permissions make the interface easier to explore.

## 00:22 — 02  /  PERSONALIZE FEEDBACK

Before starting, the user chooses audio, vibration, or both. Detection sensitivity and announcement pacing can be adjusted to reduce distracting repetition. Accessibility options include large text and high contrast. Preferences are saved locally.

## 00:42 — 03  /  MOBILE OBJECT AWARENESS

The user opens Mobile Mode and starts assistance. The bundled object detector runs on the phone. Its alert policy selects relevant object names and relative directions for offline speech and finite vibration. The user can pause, resume, or stop. Visual risk is estimated; this is not exact distance measurement.

## 01:06 — 04  /  SCAN A PRINTED PAGE

To read print, the user opens Scan Document from Modes, aims at the page, and chooses Scan when ready. Local text recognition extracts the words for the spoken reader. The demonstration uses synthetic print. Camera images are never sent to an AI provider.

## 01:25 — 05  /  CONTROL THE READER

After scanning, the reader can speak the document aloud. The user can pause, repeat, move between reading lines, spell words, and change reading speed. Scan Again returns to framing and waits for another explicit scan. Ask AI first creates an editable text draft; sending it is a separate choice.

## 01:47 — 06  /  LOCAL APP CONTROLS

For hands-free operation, the open app supports Hey Vision AI and local commands for navigation, settings, and reader controls. Typed commands offer another route. These approved actions execute on the phone. Say goodbye to end the active command session.

## 02:05 — 07  /  OPTIONAL WEARABLE

The optional wearable uses a Raspberry Pi camera on a private network or phone hotspot. The user discovers the device, establishes trust, and connects to start. The Pi detects locally and sends compact alerts for phone speech. Physical hardware acceptance remains pending.

## 02:21 — 08  /  OPTIONAL SMART AI

Smart AI adds general questions through an explicitly paired laptop running local Ollama. An owner-enabled Gemini option accepts text only, with local fallback. Pairing is optional: object awareness, document reading, and local app controls remain independent of this conversation service.

## 02:38 — USER JOURNEY  /  COMPLETE

The journey is simple: open, personalize, detect or read, then pause or stop when finished. AI Blind Assistant supplements a white cane, guide dog, and user judgment. It never guarantees a clear path.
